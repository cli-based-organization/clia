- 1. Le système d'information (SI) clia fournit des ressources informationelles instrumentées
- 2. Les ressources informationnelles clia (RIC) sont manipulables à la fois par 1. des humains, 2. des automatismes (algorithmes déterministes) et 3. des agents IA (algorithmes non-déterministes)
- 3. clia est un SI évolutif dont le statut est déterminé par un hash de graphe ou une version fixée par un humain
- 4. le SI clia fournit un cli et un ensemble de conventions
- 5. la compatibilité d'une ressource est avec le SI clia (cli et convensions) est déterminé pour une version donnée
- 6. une ressource compatible avec le SI clia est nommée une ressource clia (RIC)
- 7. une RIC est polymorphe. Elle peut prendre la forme 1. d'un fichier, 2. d'un répertoire contenant des fichiers et des répertoires imbriqués, 3. un repo git ou 4. n'importe quel réceptacle contenant des informations
- 8. Une RIC a 3 types d'information:
  - 1. une information d'identification
  - 2. une information d'essentialisation
  - 3. une information accidentelle
- 9. l'information d'identification est contextuelle, elle peut prendre des formes différentes selon le contexte.
- 10. l'information d'identification est immuable et unique.
- 11. l'information d'identification dit qui/quel est cette ressource

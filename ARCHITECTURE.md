## Répertoires conventionnels, Zones et Status des ressources

Les répertoires conventionnels sont les suivants:

```
- $ZONE/
  - ressources/          # ensemble des ressources livrables
  - logs/                # historique 
  - session/             # répertoire de la session active
  - source-material/     # fichiers importés d'une autre source
  - templates/
  - src/
  - tests/
  - doc/
  - assets/
  - extensions/
  - archives/
```

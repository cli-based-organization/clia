# Améliorations nécessaires

## Gestion et visualisation de la configuration

Une instance installée de clia a une configuration: ensemble des éléments (PATHs, variables d'environnements, options, etc.) qui module le comportement de clia.

Ces éléments de configuration sont des ressources instrumentés par la commande `clia setup config [...]`.

Remplacer `clia context` par => `clia setup config ls`
